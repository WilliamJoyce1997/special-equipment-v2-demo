# OpenCMMS V2 功能盘点

审计基线为 `6a1d4a3` 的本地工作树（2026-11-12）。范围是 V2 的 21 个导航入口及其可达弹窗、打印页和数据读写路径。根目录 Django/P0 的工单、保养、备件与认证接口不计入 V2。旧交付 README 可作为历史需求证据，当前状态以实际配置、事件分派和存储路径为准。

- **已实现**表示当前 V2 存在可执行的完整路径。**部分实现**表示只有部分字段、权限或流程可执行。**仅模拟**表示作用于虚构样本、会话或只读预览。**未实现**表示无可达处理或明确禁用。**无法确认**用于缺少实测环境或业务依据。浏览器脚本失败和覆盖边界见[代码审查](v2-code-review.md)。
- [导航注册](../static/v2/config.js#L532)包含九类设备、一类单位、一类人员、六类产品、一类附件和三类组合查询。以页面脚本实际加载顺序执行配置后，前 18 个入口均有本地样本，合计 110 条（设备 72、单位 4、人员 4、产品 20、安全阀 10；初始存储为空）。后三个入口从已加载数据查询，初次使用没有预设方案。

## 设备管理（9/21）

七类设备共享[主列表入口](../static/v2/app.js#L187)，管道两类使用[通用页面入口](../static/v2/app.js#L303)。共同支持提交查询、空态、重置、选择、排序、分页和字段设置；表格配置独立存于 `localStorage`，普通设备业务数据来自 `fixtures.js`。地区为离线级联，设备类别及专属字典按类型读取。高级字段和列数按实际运行时 schema 计数，列数不含序号、选择和操作列。下表中的脚本是可定位的覆盖入口，不等于本轮全部通过。

| --- | --- | --- |
| 01 锅炉 | 19/38 项、36 列。燃料及设计燃料级联、额定蒸发量/热功率区间、水质检验和安全阀字段。见 [锅炉 schema](../static/v2/config.js#L544)。 | 精简档案、设备信息、更多菜单、同使用单位批量更改检验机构、XLSX。档案只读，改机构仅当前会话，历史报告保留原机构。无设备新增、删除、导入或设备打印。测试 `boiler-alignment`、`dossier`、`pages`。 |
| 02 压力容器 | 17/158 项、30 列。用途、快开门、分级类别，高级检验和建造字段按[共享 schema](../static/v2/config.js#L761)适配。 | 同七类公共操作；最近有效检验从年度／全面记录中选择，避免混用关联字段。无设备新增、删除、导入或设备打印。测试 `equipment-common`、`device-scope`、`pages`。 |
| 03 电梯 | 21/49 项、51 列。梯龄、基准月、保险、按需维保、检测机构及检测状态等；详情八个标签。 | 另有批量属性/维保调整、使用标志打印、检测信息和检验检测更正。打印依赖新窗口及 `sessionStorage` 短期快照，非正式证照；更正及批量修改为会话内更新。测试 `elevator-refinement`、`elevator-more`、`pages`。 |

| 05 场（厂）内机动车辆 | 16/37 项、26 列。厂牌编号、车辆分级、场所、载荷和额载最大运行速度。 | 同七类公共操作，场所/类别与其他类型分开。无设备新增、删除、导入或设备打印。测试 `vehicle-refinement`、`device-scope`、`pages`。 |
| 06 大型游乐设施 | 15/36 项、27 列。场所、运行速度、限速器；水上与无动力设施有下级类别。 | 同七类公共操作，场所独立。无设备新增、删除、导入或设备打印。测试 `amusement-refinement`、`equipment-common`、`pages`。 |
| 07 客运索道 | 15/37 项、25 列。索道类别分级、公众聚集场所、斜长、速度、安全阀。 | 同七类公共操作。无设备新增、删除、导入或设备打印。测试 `ropeway-refinement`、`device-scope`、`pages`。 |
| 08 压力管道装置 | 11/32 项、13 列。类别、创建和办理日期、告知编号、管线数、全面检验日期；查询字段可配置。 | [新增入口](../static/v2/app.js#L467)仅打开可编辑草稿，表单只有关闭动作，[没有保存入台账](../static/v2/dossier.js#L494)。可选虚构检验单位；详情含按 ID 关联的管线。选中同单位同类别装置可预览在用管线汇总；主列表支持 XLSX，汇总无单独导出或打印。测试 `installation-refinement`、`installation-detail`、`pipe-query-settings`、`pages`。 |

## 单位与人员（11/21）

| 模块 | 查询与表格 | 操作、存储、限制和验证入口 |
| --- | --- | --- |
| 10 检验单位 | 名称、信用代码、地区级联、联系人、超期。高级含机构等级/类型及同一资质的项目、编号、日期，部分字段禁用。8 列，排序、分页、选中、字段设置。见 [配置、匹配和存储](../static/v2/inspection-unit.js#L35)。 | 编辑单位、批量删除、资质新增和删除、修改记录查看、XLSX。数据写入 `v2:inspection-units:v1`，没有独立新增单位、导入、打印或外部资质获取。历史为演示资料。测试 `inspection-unit-refinement`、`inspection-unit-info`、`pages`。 |
| 11 人员信息管理 | 综合关键词、地区、持证状态、来源。高级含手机号及资格的日期、编号等 7 项，部分选项尚无有效字典值。9 列，排序、分页、选中、字段设置。见 [人员 schema](../static/v2/personnel.js#L98)。 | 档案编辑入口为只读，资格查询、修改记录可查看，资格新增/删除禁用。Excel 导入有 [jyryExp.xls 模板](../static/v2/templates/jyryExp.xls)、预览校验、批量存储到 `v2:personnel-import:v1`，支持 XLSX 导出。无单条新增、删除、打印。单位删除后人员关联重排是已证实缺陷。测试 `personnel-refinement`、`personnel-import`、`pages`。 |

## 产品管理（17/21）

六类共用 [注册与编辑/复制/检验入口](../static/v2/boiler-product.js#L81)和[按类型的导入 schema](../static/v2/product-import.js#L12)。主表支持搜索、排序、分页、选择、字段设置与全查询结果 XLSX；产品界面不显示高级查询入口。导入模板及修改写入 `v2:products:v1:<type>`，本轮以各模块的处理器判定，不沿用旧文档中的“CSV”“导入禁用”。复制建立独立 ID 的会话记录，修改记录/检验信息为演示查看，无正式工作流，无产品批量删除和打印。

| 模块 | 查询、表格和编辑差异 | 模板与专项验证 |
| --- | --- | --- |
| 12 锅炉产品管理 | 综合关键词、制造单位、类别级联，8 列、5 条样本。可编辑类别及许可的产品参数，含压力、热功率等锅炉参数。 | `product-boiler.xlsx`；`boiler-product`、`product-import`、`pages`。 |
| 13 压力容器产品管理 | 同三类查询，8 列、3 条样本；资料大多只读，类别可修改。按本类压力容器级联字典。 | `product-vessel.xlsx`；`vessel-product`、`product-import`、`pages`。 |
| 14 电梯产品管理 | 同三类查询，8 列、3 条样本；产品类别级联和电梯专属参数可按表单规则编辑。 | `product-elevator.xlsx`；`product-batch3`、`product-import`、`pages`。 |
| 15 起重机械产品管理 | 同三类查询，8 列、3 条样本；产品类别级联、起重参数与电梯配置分开。 | `product-crane.xlsx`；`product-batch3`、`product-import`、`pages`。 |
| 16 管道元件产品管理 | 同三类查询，8 列、3 条样本；类别可改，其他资料主要只读，制造单位搜索等辅助入口禁用。 | `product-pipe-component.xlsx`；`pipe-products`、`product-import`、`pages`。 |
| 17 管道工程产品管理 | 综合关键词、制造单位、执行标准，10 列、3 条样本；独立工程表头，查看表单只读。 | `product-pipe-project.xlsx`；`pipe-products`、`product-import`、`pages`。 |

产品模板在 [静态模板目录](../static/v2/templates)，页面下载名由 schema 设置，文件名与部署路径可不同。产品编辑按 `readonly`、类型与可用类别配置决定控件；未将按钮标签“编辑”作为所有字段可改的证据。

## 安全附件（18/21）

**18 安全阀管理。** 普通查询使用单位、装置、检验/下检日期范围、产品编号；无高级查询入口。9 个业务列、10 条初始样本，支持排序、分页、选择、字段设置。已实现新增、编辑、复制、删除及检验信息修改，校验含必填、日期、压力和编号，按 [提交过程](../static/v2/safety-valve.js#L28)写入 `v2:safety-valves:v1`。Excel 导入有 28 列原版模板、校验和预览，[工具栏](../static/v2/safety-valve.js#L41)仅新增/导入/删除，当前无导出和打印。修改记录是演示展示。专项脚本 `safety-valve`，`pages` 覆盖菜单和模板下载。

## 查询统计（21/21）

三个入口使用 [方案列表](../static/v2/query-plans.js#L22)、[四步构建器](../static/v2/query-builder.js)、[类型化引擎](../static/v2/query-engine.js)和[结果表格](../static/v2/query-results.js#L80)。共同支持方案创建人/时间筛选，方案新增、编辑、删除、执行，组合条件和结果列配置，方案/结果表格排序、分页、选择和字段设置，结果 CSV。方案在按域隔离的 `localStorage` 键内，查询不写源记录；无条件剪贴板导入、Excel 导入、打印或真实跨账号方案共享。

| 模块 | 数据和联动 | 测试与限制 |
| --- | --- | --- |
| 19 人员综合查询 | 38 个字段定义，分检验人员、无损检测人员；资格条件按同一关联记录计算。 | `query-engine`、`person-query`、`query-builder-refinement`、`pages`。人员单位关联取当前单位数据，继承人员重排问题。 |
| 20 单位综合查询 | 13 个字段，八类单位；检验单位复用本地档案。 | `query-domains`、`pages`。其余七类明确没有数据源，能配置不等于能查到真实资料。 |
| 21 设备综合查询 | 按设备类型复用档案字段；装置/管线明确分支，历史条件按同记录匹配、设备结果聚合。 | `query-domains`、`device-scope`、`pages`。缺资料及旧字段迁移失败有提示，未接外部台账。 |

三类字典和适配逻辑以 [query-dictionaries.js](../static/v2/query-dictionaries.js#L23)为准。没有独立的持久 IndexedDB 业务库。产品、人员及安全阀 Excel、设备二维码和电梯打印均可在本地浏览器处理；原系统未公开功能、真实后端行为、法定证明效力和真实账户权限无法确认。
