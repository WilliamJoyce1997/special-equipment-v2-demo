## 2. 可操作的核心路线

| 步骤/账号 | 实际点击位置 | 操作与预期 |
| --- | --- | --- |
| 1 demo_manager | 设备台账→新增设备 | 编号DEMO-SE-LIVE-时间戳，名称“虚构演示电梯”，类别电梯，负责人“演示使用单位主管”，型号/安装位置等按需填写；保存后建档/未投用 |
| 2 demo_manager | 对应设备行→详情 | 基本档案可看使用单位、负责人、状态、模拟检验日期；编辑可填人工模拟下次日期，系统不推算法定周期 |
| 3 demo_manager | 详情→申请模拟准入 | 填模拟确认原因→提交确认，进入待模拟准入确认 |
| 4 demo_manager | 详情→确认模拟投入使用 | 再填原因→提交确认；只有虚构编号/is_demo及有效演示条件满足、无阻断问题时变为在用/运行中；并非真实放行 |
| 5 demo_manager | 详情→服务单位授权 | 选“演示恒护维护单位C”/维护，保存；再次选“演示迅修维修单位D”/维修，保存。有效期可留空，表内可撤销授权 |
| 6 demo_manager | 保养计划→新增计划 | 选本设备、唯一计划编码、日常周期、默认维护单位C和维护员；保存 |
| 7 demo_manager | 计划行→生成工单 | 生成PM并按默认人员分配；同日重复生成返回已有工单，未到下一周期拒绝重复新建 |
| 8 demo_maintenance | 工单管理→对应工单详情 | 接单→开始/维修进场→处理过程（填过程）→完工反馈（处理措施必填）；到已完成 |
| 9 demo_manager | 工单管理→对应PM详情→使用单位确认关闭 | 工单关闭，设备等待独立模拟复用确认；回设备详情重复步骤3/4恢复演示在用 |
| 10 demo_manager | 点检记录→点检计划→新建点检计划 | 选设备、seed模板“电梯日常观察Demo”、点检员demo_operator、开始日期为今日、频次1天；保存→生成当日任务 |
| 11 demo_operator | 点检记录→点检任务→执行点检 | 各项目正常、实际执行时间→提交点检；产生正常记录 |
| 12 demo_manager | 点检记录→点检计划→新建点检计划 | 为同设备建立另一个唯一“异常复查”计划，执行人仍为点检员→生成当日任务。不同计划保证不破坏同计划同日幂等 |
| 13 demo_operator | 对应异常复查任务→执行点检 | 门区观察选择异常、填写虚构门区异响，其他正常→提交；设备停用，保留正常历史 |
| 14 demo_operator | 当前记录详情→上报维修 | 创建唯一CM工单；重复上报不重复建单；“查看关联工单”可跳转 |
| 15 demo_manager | 工单管理→该CM详情→分配任务 | 选维修单位D和维修员；变已分配 |
| 16 demo_repair | 对应CM详情 | 接单→开始/维修进场→处理过程→完工反馈；填模拟处理措施、根因、工时，变已完成；无使用单位关闭权限 |
| 17 demo_manager | 对应CM详情→使用单位确认关闭 | CM已关闭，但设备不会自动运行；“查看来源点检”可返回异常记录 |
| 18 demo_manager | 点检记录→执行记录→异常记录详情→复核已解决 | 填模拟复查依据；只有关联维修已关闭才能复核。问题解决后仍需独立模拟复用 |
| 19 demo_manager | 设备详情→申请模拟准入→确认模拟投入使用 | 分两步填原因，设备恢复演示在用；仍有阻断问题则拒绝并显示原因 |
| 20 demo_manager | 设备详情→生命周期 | 建档、授权、维护、点检、维修、问题复核及状态事件按时间可查，显示单位、人员、时间及来源，部分事件有来源按钮 |
| 21 demo_manager | 报表统计 | 选择该设备、合适日期范围→刷新统计；该路线应检2、完成2、完成率100%、异常记录1、CM完工1/待修0。下次日期提醒标人工模拟来源 |
| 22 demo_manager | 备件管理→新增备件 | 初始库存0；入库5→出库2→流水，可看两条流水及前后库存，最终3；库存不足拒绝，不产生半条流水 |
| 23 demo_other | 设备台账/工单管理/报表统计 | 本单位只能看到另一虚构单位设备，不能查看本路线设备或任务 |

没有新增检测/检验CRUD入口。报表的检测/检验结果区明确提示P0未接入，不能用日常点检结果冒充法定检验。
