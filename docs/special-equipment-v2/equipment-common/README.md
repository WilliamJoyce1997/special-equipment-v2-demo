## 第一阶段：公共实现
锅炉、压力容器、电梯、起重机械、场（厂）内机动车辆、大型游乐设施、客运索道共用 V2EquipmentPage 控制器；各类型单独保存查询、结果、分页、选择、字段配置状态。
V2EquipmentSchema 提供公共受理状态、主管部门、重要场所、设备使用场所、注册状态及离线省市县资料。现有锅炉专属字典通过类型适配保留；未将锅炉检验类别、燃料等复制到其他类型。
七类主页面均使用两级地区、悬停帮助、查询设置、高级/普通切换、同单位机构变更和真实CSV导出。其他类型高级字段从各自现有详情字典提取，不手工维护七套清单；没有来源的值仍为空，不补造资料。
已存在的详情、全部、检验详情和电梯检测弹窗中的同名通用字段通过同一选项接口取得。地区只读展示也采用同源省市县；没有对应字段的视图不额外添加。
表格继续复用现有V2QueryResults，原业务表头不变；导出保留完整业务字段，存在选择时导出已选，否则导出当前查询结果。未查询时不隐式导出全部数据。
机构变更只允许非空且同一使用单位的选中集合。当前样本使用单位名称是已有分组依据；不引入新单位关系或数据库模型。变更保留旧历史机构，包括原为空的情况。
离线地区仍为上一轮2023快照；旧“演示省”样本统一标注云南省/昆明市作为虚构样本展示位置，不能据此视为真实设备地址。旧通用演示枚举做明确映射；无法映射的主管部门和使用场所留空。

## 第二阶段：压力容器
主查询保持参考图三列顺序和17个查询项。设备类别5组、14个子类别，旧目录可直接选中；父项切换清除旧子项。
使用状态6项、设备用途9项、快开门是/否，均另有“请选择”。查询与只读详情/参数区使用相同字典，未混入锅炉参数。
采用“罐式集装箱”，与此前人工确认的产品字典和本轮设备用途文本一致。本轮图片未展示该展开选项，未登录原网站独立核验“罐弎”原文。
压力容器高级区复用本类型现有完整详情字段，其展开长度较长；可用查询条件设置隐藏及排序。字体、图标和日期控件沿用现有V2，未声称像素级还原或已核验原网站高级字段全清单。
机构修改仅当前会话有效；未更改历史检验数据和任何法定状态。
