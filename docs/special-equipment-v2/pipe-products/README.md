## 主表与数据

两页各3条明确虚构产品，初始为空，查询后加载；支持重置、排序、分页、选择统计、列设置、CSV及横向滚动。
导入继续禁用并提示未提供文件解析。复制真实新增当前产品类型的会话记录及独立内部标识，完成后才提示复制成功。

管道元件：独立复选框之外完整10列：
序号、操作、设备代码、产品名称、制造单位、产品型号、产品编号、设备类别、创建日期、备注。

管道工程：独立复选框之外完整12列：
序号、操作、制造单位名称、工程项目名称、合同编号、执行标准、委托方（订货单位）、车号、出证日期、总长度、规格、钢级。
“钢级”为最右列，显示值与CSV均已核对。没有额外增加设备台账字段作为工程表头。
工程查询为综合查询、制造单位、执行标准，独立配置，不套用元件类别查询。
工程记录包含用于共用复制逻辑的内部DEMO编号，这些不是工程合同号，也不作为额外表头或真实设备代码展示。

## 元件字典

父项/子项严格为：
- 压力管道管子：球墨铸铁管、复合管、无缝钢管、焊接钢管、有色金属管、非金属材料管。
- 压力管道管件：非焊接管件（无缝管件）、焊接管件（有缝管件）、锻制管件、铸造管件、复合管件、非金属管件。
- 压力管道阀门：安全阀、金属阀门、非金属阀门、特种阀门。
- 压力管道法兰：钢制锻造法兰、非金属法兰。
- 补偿器：金属波纹膨胀节、旋转补偿器、非金属膨胀节。
- 压力管道密封元件：金属密封元件、非金属密封元件、压力管道特种元件、防腐管道元件、元件组合装置。

查询、编辑及样本共用同一字典，父项变更清空旧子项。保留用户给定父子关系，不擅自移动特种元件等条目。

## 通用组件及隔离

编辑、复制、更多菜单均接入既有产品组件；菜单为修改记录、检验信息。新两页按指令使用“更多>>”，原四页按钮文字保留。
修改记录与产品检验信息分别使用已有共享组件，按产品类型及产品ID取数；不读取设备、人员或其他类型产品记录。
当前修改记录为空，不把前端查询或复制冒称为服务器审计。检验信息仍为模拟会话数据，无法定效力，不影响设备准用状态。
