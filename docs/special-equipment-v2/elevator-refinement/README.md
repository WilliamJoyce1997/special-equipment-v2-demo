## 配置边界
七类设备的使用状态均为在用、停用、报废、拆除、安装告知中、注销登记，另有请选择。主查询、详情、参数、全部及相关弹窗从同源字典读取。
锅炉场所保持原值；压力容器改为学校、车站、商场、场馆、公园、宾馆、医院、工厂、其它；电梯采用本轮21项。其他四类保留其现有内容，以独立数组承载，不宣称已根据原网站核实其场所选项。
主要问题共享同一字典。电梯“检验主体组织单元”独立使用inspectionSubjectUnit，未与锅炉organizationUnit合并。
电梯类别5组10个子项，旧目录可直接选择，父项切换清除子项。普通查询购买保险有/无，基准月12项。
49项高级字段按截图逐项配置，三列排列；检验结论禁用。重复出现的基准月、梯龄与办理日期等控件同步，避免同名表单项覆盖已填条件。
制造日期绑定既有manufactured，创建日期绑定created。没有来源的值保持为空。未将原“定期检验（模拟）”等旧样本自动解释成正常检验，也未将旧混合性质自动解释为检验/检测；只读字段旁标注未归类原演示值。历史记录仍保留原始样本身份，筛选菜单仅显示电梯四项类别。
现有“检验检测更正”同键性质也使用检验/检测；仍保留原校验与未知旧值必须明确选择后才能保存的规则。

## 工具栏及数据作用范围
更改检验机构仍需非空且同一使用单位的选择。使用标志与工具栏更多需至少选择一条；与行内五项更多菜单完全独立。
重要场所/风险等级校验选择后仅更新选中电梯；取消不保存。更新维保包含七项字段、必填验证、日期检查、现有虚构维保单位搜索选择。多个选中记录的同一字段值不同时初始留空，避免混用某一条记录；保存后统一应用用户确认的值。未伪造后台审计。
维保修改反映到列表、详情、打印与当前会话查询；刷新恢复前端样本。不写SQLite，不自动调整法定日期、许可或检验结论。

## 打印
列表使用标志实际打开 /scdrpt/rpt_printCrt.shtml?demo=... 。v2_server.py将该路径精确映射到静态打印HTML，其他原有白名单和本地访问限制不变。
当前选择支持单条或多条，每条独立模板页；通过同源新窗口的sessionStorage快照传递少量虚构展示字段，随机token、1小时有效，不写localStorage或服务器。新页读取后断开opener；直接访问缺少上下文时显示明确提示，不显示其他设备。
有左侧目录/模板、偏移、版式/缩放、套打、网页打印、控件打印和关闭。二维码使用现有本地编码库。演示水印和无法定效力说明在套打与打印时仍保留。
网页打印调用浏览器window.print。当前环境没有原网站专用打印控件，控件打印明确说明后询问是否转浏览器打印，不声称控件安装或打印成功。
测试实际生成print-demo.pdf；验证两种按钮调用打印、参数生效和关闭返回。未连接实体打印机，纸张边距、驱动和实物输出仍需人工验收。
