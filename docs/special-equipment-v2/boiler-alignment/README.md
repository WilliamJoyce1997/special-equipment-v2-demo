# 锅炉校对与精简档案滚动修复（2026-11-03）

本轮仅调整锅炉设备模块及指定七类设备精简档案滚动。未修改数据库、后端、其他业务模块或执行 Git 提交；参考截图未保存到项目。

## 修改文件
- static/v2/config.js：锅炉独立字典、地区数据、普通及高级查询字段和筛选规则。
- static/v2/fixtures.js：仅规范锅炉前端演示值。
- static/v2/app.js：锅炉查询页控制器、查询/表格设置、机构调整及七类精简档案滚动接入。
- static/v2/dossier.js：锅炉同名字段字典、历史机构保留。
- static/v2/inspection-history.js：锅炉检验类别一致性。
- static/v2/inspection-record-dialogs.js：锅炉检验详情选项一致性。
- static/v2/styles.css：锅炉页面/设置/帮助及单滚动容器的局部样式。
- tests/v2/boiler-alignment.test.cjs、tests/v2/boiler-alignment.e2e.cjs：本轮针对性检查。

## 已完成
普通/高级查询在同页切换；38项高级字段按截图排列（两处社会信用代码使用独立字段ID）；类别和燃料级联；31省份及对应市县的两控件联动；查询前与重置后空表；范围查询包含边界，缺失值不作为0。
设置支持显隐、拖动排序、还原和保存；表格支持颜色与冻结前缀，完整字段CSV不因隐藏列丢失。
更改检验机构仅允许同一使用单位的实际选中记录，保存仅修改当前前端会话，历史报告机构不被覆盖。
七类精简档案仅正文纵向滚动，外层不滚动，重复打开回到顶部。

## 验证
最终：锅炉规则8项、浏览器15项通过；相关查询域13项、电梯5项、装置详情11项回归通过，共52项通过，最终失败0、跳过0。未运行全量测试。
浏览器覆盖1366、1920、390宽度，七类精简档案、枚举、级联、设置、筛选、导出、机构限制及历史保留；未观察到阻断性脚本错误或网络写入。数据库比对未变化。
过程曾发现历史机构空值保存、重复打开档案停留中部的问题，已修复；测试曾因服务尚未就绪连接失败、报告写权限不足中断，确认服务及使用授权写权限后重跑通过。failure.json保留过程失败记录，最终结果以browser-results.json和engine-results.json为准。
