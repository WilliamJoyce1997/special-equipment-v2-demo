## 完成情况

电梯菜单严格为：智慧监管码、检验信息、检测信息、检验检测更正、修改记录。其他八类操作不变。

检测信息：五项当前电梯只读信息，类别/状态采用只读下拉外观；可折叠“已完成检测信息”，独立复选框与完整8列表头、分页统计和确认/取消。仅读取 testingRecords 中 equipmentId 对应记录。现有样本没有完成检测报告记录，因此显示空表，不把 testingDate 或基础资料伪造成报告。

更正：11字段按三列四行排列；安装监检日期、最后一次监督检验类型、基准年、基准月四项必填；梯龄只读且不在保存白名单内；监督检验类型与当前检验检测性质使用用户指定字典，信息确认默认未确认。保存仅更改当前行前端对象；取消、关闭、Escape不保存。详情最新检测信息和列表共用该对象，重新打开即同步。刷新恢复原始样本，不写服务器、不创建审计或检验记录、不自动计算法定周期。

旧样本“定期检验与自行检测（模拟）”不属于本轮指定性质字典，打开更正时不擅自推断为某个新选项，保存前要求明确选择。
