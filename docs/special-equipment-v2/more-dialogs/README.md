# 更多行操作三个弹窗交付

日期：2026-10-30。继续在现有V2独立副本开发，访问 http://127.0.0.1:8020/ 。

## 实现与参考

仅在对话中读取本轮三张参考图，没有复制参考图到项目或创建参考图归档。当前目录screenshots为实际浏览器运行截图。

三个入口均支持设备管理九类设备，打开时固定设备类型、设备ID与当前行；关闭或切换弹窗清空其局部状态。背景列表的查询、页码、排序、选择保持不变。

### 智慧监管码

左右分栏，左侧智慧监管码、使用单位名称、使用单位地址、设备类别、设备代码、设备注册代码、产品编号；右侧本地生成黑白二维码；底部居中关闭。
智慧监管编码对应row.regulatoryCode，设备代码与注册代码分别读取自己的字段。产品编号只读productNumber，不把出厂编号拼成产品编号；单位地址只读unitAddress，不用设备安装地点代替。未提供显示“—”。

二维码内容为JSON：demo=true、system=OPENCMMS-V2-DEMO、type、id、equipmentCode。无电话、证书或真实监管URL。
采用本地qrcode-generator 2.0.4，自动版本、M纠错、4模块静区及整数像素绘制Canvas。运行时无在线二维码接口。
测试由独立jsQR 1.4.0读取实际Canvas RGBA解码：九类全部成功，内容各异；同类别不同记录亦不同；脚本加载后断网仍可生成。不是随机方块；生成库不可用时显示明确错误且不放置假二维码。
没有进行真实手机硬件扫码测试；验证方式为标准软件解码。

来源：[qrcode-generator官方仓库](https://github.com/kazuhikoarase/qrcode-generator)、[jsQR官方仓库](https://github.com/cozmo/jsQR)。发行包完整性及文件SHA-256记录于dependencies.json；许可证保留，未更改原项目LICENSE。

### 历史检验信息

使用V2Dossier.histories(type,row)，与原设备信息子标签为同一函数和同一数据；未添加另一套虚构检验记录。

|区域|业务表头（不含独立复选框）|行为|
|---|---|---|
|已完成检验信息|序号、操作、检验类别、检验结论、检验日期、下检日期、检验机构、检验部门、检验性质、报告编号、业务流水号、来源、添加人、添加时间|类别筛选、按各类别最新、每页数/分页、选择与蓝绿统计|
|正在检验流程|序号、操作、检验类别、申报时间、业务流水号、办理环节、报告书编号、申报单编号|独立空表、分页及0条统计；未把完成记录复制为进行中流程|
|延期检验申请|序号、操作、未检原因、检验类别名称、下次检验日期、延期检验至、申请人、申请日期、备注|独立空表、分页及统计；登记禁用，不调整日期|

操作列复用全站约定，所以正在检验流程比截图增加一列只读“操作”；其余表按用户完整清单。

锅炉保留内部检验、外部检验、水质检验、安装监检、驻厂监检、进口监检六项。其他设备的弹窗只提供其已有虚构样本类别（如容器全面/年度），不套用锅炉专属记录；详情原选项结构保留。
“各类型最新”先按检验日期降序、日期相同按稳定ID升序，再取每类第一条，不改变源记录。

详情在同一弹窗内打开只读子视图，可返回保留历史表状态。报告、报告附件、意见书统一提示“演示数据暂无对应文件”，不生成法定报告。
新增/删除和登记按钮禁用并说明演示模式不支持修改或提交。记录不删除、不写库，延期申请不等于批准。

### 历史修改记录

三列查询：修改人姓名、字段名称、上传时间开始/结束；下方居中查询/重置。支持组合筛选，非法日期范围明确报错。表格排序、分页、选择、空状态、横向滚动和蓝绿统计。

业务表头：序号、操作、修改人姓名、所在部门、字段名称、修改类型、字段代码、修改前值、修改后值、修改日期、账号。
保留全站“操作”列，额外提供只读详情，因此原10列加操作为11列，另有复选框。

只映射当前行预置row.history；没有历史的设备默认空。身份、部门、账号均虚构；上传时间基于预置记录日期作为演示筛选时间，不是真实服务端上传记录。
查询、排序、切换标签、打开窗口均不产生审计记录。

## 组件与生命周期

- 新增static/v2/more-dialogs.js组织三个视图，避免把逻辑堆入app.js。
- 复用已有dialog、recordTable、分页、选择、统计、历史检验表字段与数据。
- 共享表格只增加可选操作/工具栏/排序接口；既有视图默认行为与布局不变。
- 仅一个原生dialog，无多层遮罩；记录子视图在同一弹窗内切换。
- 关闭按钮同步清理数据与滚动锁；Escape通过原生close回调清理，幂等处理避免重复恢复。

- 没有新增API、数据库表或迁移；运行请求均本地GET。

## 未实现与差异

- 没有模拟文件，因此报告/附件/意见书只说明暂无文件；不伪造真实检验证明。
- 新增、删除、延期登记禁用；真实存储、审计、审批、延期批准、政府平台对接不在本轮范围。
- 部分设备没有已有检验历史或修改历史，按真实样本情况显示空表；缺地址/产品编号显示“—”。
- 原生日期/下拉、字体及图标与参考图有细节差异，保留已验收的主导航/配色；没有大规模重构。
- 只做软件解码验证，未用实际手机摄像头实测。

8020保持运行；本轮完成后停止开发，等待人工验收。
