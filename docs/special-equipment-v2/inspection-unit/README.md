# 检验单位 Demo 交付记录

## 范围

新增“基础档案管理 → 单位管理 → 检验单位”，沿用菜单中既有 inspection-unit 标识。没有创建验收单位，也未将检验单位等同于验收单位。

仅使用前端虚构数据，不调用写入 API、不修改数据库及迁移，不操作 P0/8010，不提交或推送 Git，不保存本轮参考图片。

## 文件清单

- static/v2/inspection-unit.js：新增单位配置、4 条虚构样本、菜单、只读编辑预览、资质管理。
- static/v2/app.js：为现有查询/表格接入单位行操作、禁用删除、单位高级查询、全查询结果导出及可配置分页。
- static/v2/dossier.js：通用表格新增可选 omitOperation；默认行为不变，单位修改记录严格使用十个表头。
- static/v2/more-dialogs.js：现有修改记录组件支持 organization 上下文，单位记录按 entityId 过滤，设备行为保留。
- static/v2/styles.css：单位菜单高亮、固定选择列及单位弹窗响应式/单一正文滚动。
- static/v2.html：加载单位模块。
- v2_server.py：仅增加新静态脚本白名单。
- tests/v2/inspection-unit.e2e.cjs：新模块针对性浏览器测试。
- 本文、test-results.json、screenshots/ 下九张实际浏览器截图。

未改动原九类设备配置、虚构设备样本、精简档案或七个设备详情页面结构。

## 单位数据与表头

共 4 条单位记录，均有 DEMO 标识，名称、地址、电话、姓名、信用代码全部明确虚构。信用代码采用 DEMO-CREDIT-xxx，不能作为真实统一社会信用代码使用。

表头：独立复选框列，序号、操作、单位名称、单位地址、社会统一信用代码、地区代码、单位级别、电话、法定代表人、是否启用。共 10 个业务表头，其中 8 个单位字段。

每条有独立 ID、联系人、地区、预设超期状态、空资质集合和 1 条预置模拟修改记录。是否超期与是否启用分别存储；不推算真实资质状态。

## 可操作功能

- 三列查询，按单位名称、信用代码、地区、联系人、超期状态组合筛选。
- 超期下拉包含全部、是、否。首次进入及重置后为空，点击查询后显示匹配数据。
- 标签切换保存已应用查询、排序、分页与行选择。
- 表头排序、2/5/10/20 条分页、行选择、列设置。
- 导出当前查询下全部匹配单位，完整字段顺序与配置一致；不因选择部分行而漏导其他匹配记录。
- 删除禁用并提供演示限制说明。
- 设置沿用既有配置；高级查询提供单位级别、是否启用，不展示设备专属编号字段。
- 编辑为只读预览，明确说明“未接通编辑保存”。没有会话更新或数据库保存，不虚假产生审计记录。
- 更多菜单仅修改记录、资质两项，定位于按钮旁，在表格之外展示；再次点击、点击外部、滚动、改变页面或窗口尺寸均可关闭并清理事件。
- 修改记录完全复用设备端既有查询和表格组件；按实体类型和单位 ID 取数，不混入设备或其他单位记录。
- 资质包含申请类别、证书编号、发证日期组合查询；表格为序号、操作、申请类别、证书编号、发证机构、发证日期、有效期至，另有独立复选框。
- 当前每单位资质均为空。新增、删除、获取资质禁用并提示原因；无真实许可查询。
- 弹窗正文为唯一纵向滚动区域，宽表可横向滚动，关闭返回原列表状态。
