# 人员查询与全项目表格设置整改（2026-11-06）

本轮仅修改 V2 源文件与测试；未执行 Git 操作，未构建 dist-pages，未部署。浏览器验证地址均为 http://127.0.0.1:8020/，使用独立测试浏览器上下文。

## 实现及存储

- 人员查询：复用 V2EquipmentPage.control 的行政区划级联、字典、province/area 代码；持证状态 8 项，数据来源 2 项；高级查询按截图 7 个字段排列。批准项目、持证级别、无损检测方法只有占位项。
- 人员资格窗口的完全同名「持证级别」「批准项目」引用人员公共配置。既有「持证项目级别」不是同名字段，本轮保留。
- V2TableSettings 统一负责默认配置、配置校验和合并、保存、表格节点重排、隐藏、颜色及冻结定位；复用原 V2FieldSettings / V2Help 弹窗。
- 配置键前缀为 v2:table-fields:v1:，只保存 key/shown/color/frozen；不保存业务行、人员身份信息或查询筛选值。
- 主列表使用 main/<模块键>；统计方案使用 query-plans/<领域>；执行结果使用 query-results/<领域>/<对象>/<子类型>/<方案ID>；子表使用 records/<模块>/<表格ID>/<标题> 或 device/<模块>/<子表>。选择窗口及许可明细另有专用键。
- 同一表格不同记录使用同一展示配置，不同模块、不同子表、不同方案互不覆盖。新增字段附加默认配置，删除或无效字段不会混入当前表格。
- 序号、选择、操作列不进入可配置字段；隐藏/重排直接移动原表头、数据单元格及 col 节点，不改行数据或原事件处理器。
- 沿用已验收的冻结语义：冻结指定字段及其之前的可见字段。偏移按实际表头宽度计算，保留固定功能列。
- 所有业务字段可以全部隐藏，固定功能列保留。保存后才应用；关闭或 Escape 放弃草稿；存储失败保留原配置并显示错误；还原只影响当前表格。

## 全项目入口排查

旧版标题「表格列设置」的两处实现分支已移除：通用主列表设置、V2QueryResults.settings。原先对应 11 个通用业务列表、3 个统计方案列表、压力管道装置内的 2 个关联表入口。原 7 类设备新版入口也统一接入持久化服务。

| 范围 | 主列表与内部表格 |
|---|---|
| 设备管理 9 类 | 锅炉、压力容器、电梯、起重机械、场（厂）内机动车辆、大型游乐设施、客运索道、压力管道装置、压力管道管线 |
| 单位管理 | 检验单位主表、修改记录、资质记录、资质许可项目明细、检验单位选择窗口 |
| 人员管理 | 人员信息主表、个人资格、修改记录 |
| 产品管理 6 类 | 锅炉、压力容器、电梯、起重机械产品、管道元件、管道工程；各自修改/检验记录复用所属模块表格配置 |
| 安全附件 | 安全阀主表及修改记录 |
| 查询统计 3 类 | 人员、单位、设备综合查询的方案列表，以及每个方案的结果表 |

九类设备详情逐个检查了 56 个子标签页：普通 7 标签结构，电梯 8 标签、装置 2 标签、管线 4 标签。包括主题信息的变更表、隐患记录、附件、检验历史/正在检验/延期申请、装置关联管线与变更表、管线元件表及「全部」中的相同表格。历史检验弹窗、报告附件、产品/单位/人员修改记录也已接入。

所有已实现的业务数据表均接入。第三方库内部二维码/Excel代码及字段设置表本身不是业务数据表，不增加递归设置按钮。未实现的对象类型仅保留既有无数据源提示，不伪造业务数据或功能。
