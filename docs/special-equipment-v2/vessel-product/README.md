# 产品通用弹窗与压力容器产品 Demo

## 本轮文件

- static/v2/vessel-product.js（新增）：3条压力容器产品样本与26字段只读编辑配置。
- static/v2/boiler-product.js：保留既有锅炉接口名称，增加按产品类型注册配置；共用主表配置、表单渲染、菜单、复制与检验信息实现。锅炉行为保留，压力容器由配置接入。

- 原锅炉交付记录增加本轮后续变更说明。

## 锅炉产品补全

“更多>>>”统一两项：修改记录、检验信息，均可正常打开。
修改记录直接调用 V2MoreDialogs 的同一 audit 组件，按 entity=product、产品类型及产品ID筛选；表头、查询、日期校验、排序、分页与统计沿用已有实现。
当前两类产品均无预置修改日志，显示正常空表，不将保存、复制或查看冒称为后台审计。
锅炉编辑、会话保存及复制原有行为保留，已回归验证。

## 压力容器主表

3条独立 DEMO-VESSEL-PRODUCT-xxx 记录，制造单位名称优先沿用已有虚构制造单位。
独立复选框之外完整10列：
序号、操作、设备代码、产品名称、制造单位、产品型号、产品编号、设备类别、创建日期、备注。

支持初始空表、综合关键词/制造单位/类别组合查询、重置、排序、分页、行选择、列设置、完整CSV和统一统计。
复制共用锅炉产品实现，实际新增独立产品ID、设备代码、产品编号，加入当前类型的会话数组；不会复制其他类型的产品或检验记录。

## 压力容器编辑

标题“压力容器产品编辑”，本轮只读，底部只保留关闭按钮，无虚假保存。
26字段按图排列：
设备代码、产品名称、设备类别、产品编号、产品型号、合同号、生产编号、用户名称、是否出口、壳程设计压力（MPa）、管程设计压力（MPa）、壳程设计温度（℃）、管程设计温度（℃）、盛装介质、容积（M³）、制造单位名称、统一社会信用代码、制造许可证号、制造国家（地区）名称、制造日期、制造详细地址、制造规范、位号、许可范围、许可证级别、备注。

三级类别依次为压力容器、固定式压力容器、当前样本的第一/二/三类压力容器；均为演示配置，不据此推导真实许可结论。
壳程和管程压力/温度分别有独立数据键，不展示锅炉额定蒸发量等专属字段。
缺失资料留空，必填标记按截图仅产品编号、制造单位名称两项。只读控件与单一正文滚动复用产品表单组件。

## 共用检验与隔离

两个产品类型共用原14字段产品检验信息表单与会话保存逻辑。记录按“产品类型|产品ID”独立存放，不读写设备历史检验。
修改记录组件同时检查 product 实体、entityId 和 productType；不会展示设备、单位、人员或其他类型产品记录。
复制清空副本修改日志，不携带源产品检验信息。
