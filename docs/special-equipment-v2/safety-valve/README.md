## 页面与操作

查询条件：使用单位、装置名称、检验日期范围、下检日期范围、产品编号。首次与重置后为空表，点击查询才展示匹配记录。统计使用匹配总数和真实选中数；翻页保留选择。

表头为独立复选框，以及序号、操作、使用单位名称、装置名称、安全阀类型、安全阀型号、制造单位、产品编号、检验日期、下检日期、状态。前六个业务字段来自参考图可见部分；后三个是演示补充字段，不声称还原截图右侧完整原表头。序号及操作固定，其他列横向滚动。保留排序、分页、列设置与CSV导出；工具栏增加导出供要求的回归验证及使用。

新增/编辑共用30项字段、8项必填的双列表单，使用单位地址和制造厂家跨列；保存、粘贴、关闭位于底部。数值校验有限且非负，公称压力、公称通径、要求整定压力须大于0；必填文本、真实日期格式及重复产品编号均检查。压力等级为文本，允许截图中的“/”。关闭不保存草稿。单位及设备选择使用本地演示建议列表，没有接入真实基础档案查询接口。

复制创建独立ID与不重复产品编号，并保存会话内粘贴来源；粘贴只填表，保存后才新增。删除先选择再确认，取消不变。更多菜单复用已有浮动组件，提供“修改记录”，直接调用V2MoreDialogs的通用历史修改记录弹窗。安全阀通过entityType=safety-valve及entityId过滤，默认空记录，不生成审计数据。

## Excel导入

下载入口位于安全阀导入弹窗；文件为/static/v2/templates/safety-valve-import.xlsx。模板含30个表单字段及独立检验日期、下检日期；空日期不会自动推算。填写说明及页面均明确演示用途。

使用本地SheetJS 0.20.3，运行时不依赖在线二维码或Excel服务，不发送上传请求。来源：[官方独立脚本说明](https://docs.sheetjs.com/docs/getting-started/installation/standalone/)，原始脚本https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js，许可证与脚本一并保存。

支持真实.xlsx与.xls；上限5MB、1000条记录。检查文件扩展名及签名、工作表名、32列标题及顺序、必填项、数值、日期、下拉值、与现有记录及批内重复编号；拒绝公式、错误单元格及数值型产品编号以免损坏前导零。整批校验通过后才加入内存，有错误整批不导入并显示具体行/字段。关闭正在解析的弹窗不会提交结果。
